Sync Between Devices

This desktop version and your phone version are separate copies with separate storage — no account or server links them. This code is how you carry progress between them manually.
How to use it:
  1. On the device you just updated (e.g. checked boxes on your phone), tap Copy below — this copies a code representing everything you've checked off.
  2. Send that code to your other device however's easiest — a note to self, Messages, email, whatever you'd normally use to move text between devices.
  3. On the other device, paste the code into the "Paste a code" field and tap Load.
  4. That device now matches the one you copied from. Loading a code fully replaces the receiving device's progress — it doesn't merge, so always copy from whichever device has the most up-to-date progress.
